# Item Database

Search and filter the items this guide talks about: materials, currencies, consumables and a few pieces of gear. Click a column title to sort. The filters are saved in the address, so you can send a filtered view to a friend with **Copy link to this view**.

:::note[A starter set, not the whole game]
This list only holds items the guide uses, each with a source link and the date it was checked. It is not a copy of a full game database. If an item is missing, [add it](../10-contribute/add-an-item.md), it takes one entry in one file.
:::

<ItemDatabase />

## Using the list in a guide page
A page can show a ready-filtered list, for example only the materials:

```mdx
<ItemDatabase category="material" />
```

The reader can still change the filters. Pages that use components must be `.mdx` files, see [Add a React Component](../10-contribute/add-a-react-component.md).
