# Daily and Weekly Checklist

Mostly **level 45 content**. Weekly counters reset **Wednesday 16:00 server time**; the time zone is not published, so check the in-game "Weekly recharge in" countdown.

## Daily
| Activity | Refill / cap | Notes |
| --- | --- | --- |
| Duty Missions | 5 per day (counted per server), hold up to 20 | 50,000 **bound** Kina + 1,000 Abyss Points each |
| Nightmare boss | 2 per day, bank up to 14 | Attempt is spent only on a clear |
| Odyle Energy | +15 every 3 h (120/day), cap **560** (840 subscribed) | Builds from level 22. Conquest/Transcendence cubes cost 40, Krao Cave and Urugugu Canyon cubes cost 20 |
| Conquest reward count | 1 per 8 h, cap 21 | Holds about 7 days |
| Transcendence reward count | 1 per 12 h, cap 14 | Needs item level 1,600 |
| Shugo Festival keys | 3 per day, cap 12 (21 subscribed) | Per server |
| Dimensional Invasion key | 1 per day, cap 7 | Abyss content |
| Spacetime Rifts | 3-hour respawn | Optional trickle of Abyss Points |

## Weekly
| Activity | Amount |
| --- | --- |
| Raid attempts | 4 per raid (Ludra: 1 final-boss kill per week) |
| Ascension Trial | 3 entries |
| Subjugation tickets | 3 |
| Exploration reward counts | 7 per Expedition dungeon |
| Daily Dungeon (Unknown Fissure) | 14 entries per server, so about 2 per day. **Unlocks at level 30** |
| Abyss time | 7 h per layer (14 h Lower/Middle if subscribed) |
| Daeva Pass EXP | 50,000 per character |

## Levels 10–44
Most of the list above is locked behind level 45, item level or Odyle Energy (level 22). Before 45, the loop is: **quest → gather nodes on the way → farm leather mobs while questing → sealed dungeons** for [Enhancement and Upgrades](../06-gear/enhancement-and-upgrades.md) materials.
