# Glossary

| Term | Meaning |
| --- | --- |
| **Kina** | Gameplay currency (some sites write *Kinah*). Used for enchanting, crafting, engraving, repairs and the Market. Comes as tradable Kina and **bound Kina** (cannot be traded) |
| **Quna** | Premium currency bought with real money (shop, premium Daeva Pass). Can be exchanged for Kina by subscribers |
| **Essence Extraction** | Gathering |
| **Odyle** | A floating **crafting material** you gather in the air, see [Odyle](../03-gathering/nodes/odyle.md) |
| **Odyle Energy** | A **separate** resource that refills over time and opens reward cubes after dungeons. Builds from level 22. Not the same as Odyle |
| **Daeva** | What your character becomes at the end of the intro. Wings unlock at level 5 (Elyos) or 6 (Asmodian) |
| **Ascension** | Quest steps at levels 22, 32 and 45 that upgrade your wings |
| **Stigma** | Skill slots unlocking at levels 22, 27, 32, 37 |
| **Daevanion boards** | Progression boards: Nezekan (12), Zikel (20), Vaizel (30), Triniel (40), Azphel (45) |
| **Sealed dungeons** | One-time dungeons on the map. Give skill points, Daevanion resources, Enhance Stones |
| **Expeditions** | Party dungeons: Krao Cave, Urugugu Canyon, Fire Temple, Draupnir |
| **Gear Score / Item Level** | Gear power. Gates endgame content (e.g. 700 for Draupnir) |
| **Verteron / Altgard** | Elyos / Asmodian starter continents |
| **Eltnen / Morheim** | Later continents (Elyos / Asmodian side) |
| **Chaotic Lower Reshanta** | The Abyss, opens at level 45 |
