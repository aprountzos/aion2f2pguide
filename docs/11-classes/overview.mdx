# Classes

Aion 2 has eight classes. Open a class to see what it does and the guides players wrote for it. Anyone can add a guide: see [Write a Class Guide](../10-contribute/write-a-class-guide.mdx).

<ClassIndex />

:::note[Where the class list comes from]
The role and weapon of each class are from the public class list linked in each card, checked on the date shown on the class page. Guides are written by players, so each one shows its author, its date and its sources.
:::
