# Classes

Aion 2 has eight classes. Each card shows what the class does in a group and links to its guide. A class without a link has no guide yet: you can write it with the [guide builder](../10-contribute/write-a-class-guide.mdx), no coding needed.

<ClassIndex />

:::note[Where the class list comes from]
The role and weapon of each class are from the public class list linked in each row, checked on the date shown. Guides are written by players, so each one shows its own date and sources.
:::
