:::note[Conflicting info]
Fextralife lists Asmodian Ruby in Dredgion Crash Site, Calderon Canyon, Tranein Highland, Silent Hill and Nameless Cemetery. For the promotion quest the advice is **Calderon Canyon**, and one writer got the quest Ruby from the first node they gathered there at level 20.
:::
