# Ore — Orichalcum

- Gathered from **Proficiency Lv. 1**. One extraction gives one ore, grade by node: **Orichalcum Ore, Fine, Pure** (Radiant exists and is in demand).
- Used for ingots and the Orichalcum armor/weapon line, see [Crafting Professions](../../05-crafting/crafting-professions.md).
- One source's "first sword" route: 6 Orichalcum Ore + 2 Odyle + 3 Solvent (bought) + 5 Refining Stones. Ore only becomes Ingots once you have Solvent.
